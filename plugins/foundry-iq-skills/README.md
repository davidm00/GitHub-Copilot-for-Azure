# Foundry IQ skills

Demo preview of the [foundry-iq skill](skills/foundry-iq/SKILL.md) for Azure AI
Search and grounded Foundry IQ knowledge workflows.

This draft is for content and publication-flow review, not release approval.
Runtime evaluations have not been run. Token-budget debt and other static-check
failures are recorded in the pull request.

The skill includes a helper that can provision billable resources, change role
assignments, and update an existing agent. Do not execute it as part of reviewing
this demo; any execution needs separate approval for the resource, identity,
network, data, and cost scope.
